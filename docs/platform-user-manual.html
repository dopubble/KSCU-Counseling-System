[내담자용] 상담 플랫폼 이용 매뉴얼

🌐 상담 플랫폼 주소

https://kscu-counseling-system-production.up.railway.app
1

로그인 방법

  1. 단계 1상담 플랫폼 주소에 접속합니다.
  2. 단계 2화면 우측 상단의 [로그인] 버튼을 클릭합니다.
  3. 단계 3아이디(이메일)와 초기 비밀번호(kcu1234@)를 입력한 후 로그인합니다.

* 로그인 후 반드시 비밀번호를 변경하여 주시기 바랍니다.

2

상담사 가능 시간 확인 및 예약 방법

2회기 이후

  1. 단계 1대시보드에서 [상담 상세보기] 클릭하여 상담 상세 페이지로 이동합니다.
  2. 단계 2상담사가 열어둔 [가능 시간 달력]에서 원하는 날짜와 시간을 선택합니다.
  3. 단계 3[예약 신청] 버튼을 누르면 완료됩니다.

달력에서 파란색은 상담 가능 시간, 회색(차단)은 상담 불가 시간입니다. 가능 시간만 선택해 주세요.

3

채팅으로 1:1 문의하는 방법

  1. 단계 1[내 상담 사례 상세페이지]로 이동합니다.
  2. 단계 2오른쪽 하단 채팅 아이콘 클릭합니다.
  3. 단계 3채팅창이 열리면 문의사항을 입력 후 엔터를 누릅니다.

* 상담사가 보낸 메세지가 있을경우 채팅아이콘 위에 빨간 버튼이 있으니 반드시 메세지를 확인하시기 바랍니다.

4

상담사에게 자료 공유하는 방법

과제 및 파일 첨부

  1. 단계 1상담사에게 제출할 자료가 있을시 각 회기별 위젯에 있는 자료 첨부 버튼을 이용하여 자료를 첨부합니다.
5

상담 당일 진행 방법

본인에게 배정된 상담 방식(대면 / 비대면)에 따라 진행해 주세요

💻 비대면 상담 대상

비대면 상담은 Zoom 회의를 통해 진행합니다. 상담 당일 아래 순서대로 입장해 주세요.

  1. 단계 1[내 상담 사례 상세페이지]로 이동합니다.
  2. 단계 2당일 진행 예정인 상담 회기에 활성화된 [Zoom 회의실] 버튼을 클릭합니다.
  3. 단계 3Zoom 앱이 실행되며 상담사의 승인 후 온라인 상담방에 입장합니다.

※ 버튼이 작동하지 않을 경우, 상담사가 1:1 채팅방으로 보내준 Zoom 링크·회의 ID/비밀번호로 접속해 주세요.

🏢 대면 상담 대상

대면 상담은 상담사가 안내한 대면 상담 장소에 예약 시간에 맞춰 방문하여 받습니다.

  1. 단계 1상담 당일, [내 상담 사례 상세페이지] 또는 채팅을 통해 예약 시간·장소를 다시 확인합니다.
  2. 단계 2상담사가 안내한 대면 상담 장소에 예약된 시간에 방문합니다.
  3. 단계 3현장에서 담당 상담사와 대면 상담을 진행합니다.

※ 장소·시간 문의는 1:1 채팅으로 상담사에게 연락해 주세요.

상담사(Counselor) 이용 가이드

🌐 상담 플랫폼 주소

https://kscu-counseling-system-production.up.railway.app

수련과정 전문상담사로, 회원가입 후 관리자 승인이 완료되어야 로그인 및 업무가 가능합니다.

1

회원가입 및 승인 대기

PENDING 상태에서는 로그인·업무 불가

① 가입 유형 「상담사」 선택 후 제출

② 계정 상태 PENDING → 승인 대기 화면

③ 관리자가 ACTIVE + is_approved + 기수 설정

④ 승인 후 로그인 → 상담사 대시보드

🔒 승인 전에는 로그인하더라도 「승인 대기」 안내가 표시됩니다.
2

배정 사례 대시보드

내담자 목록 · 사례 상태 · 빠른 접근

3

사례 상세 · 채팅 · 기록 · 게시판

회기 카드 · 1:1 채팅 · 상담일지 · 초기상담 기록지 · 게시판

📝 게시글 작성

사례 상세 왼쪽 게시판 영역의 게시글 작성 버튼을 클릭합니다. 제목·내용·첨부 파일(선택)을 입력하면 이 사례 게시판에 등록되며, 내담자 상담 상세 페이지에도 동일하게 표시됩니다. 과제 안내·공지·자료 공유 등에 활용해 주세요.

📓 상담일지 (매 회기 작성)

오른쪽 회기별 상담 목록에서 각 회기 카드 하단의 상담일지 작성 버튼으로 회기별 상담 내용을 기록합니다. 내담자 매칭(담당 배정) 후 작성할 수 있으며, 상담 후 SOAP 형식으로 작성·저장합니다. 작성 완료 후에는 상담일지 보기로 열람·수정할 수 있습니다.

📋 초기상담 기록지 (1회기 작성)

1회기 카드 하단의 초기상담 기록지 작성 버튼으로 1회기 상담에 대한 초기 평가·기록을 작성합니다. 내담자 매칭(담당 배정) 후 작성 가능하며, 1회기 상담 전·후에 반드시 작성해야 하는 필수 기록입니다.

💬 우측 하단 채팅으로 일정·과제 안내

📎 회기별 내담자 첨부 파일 다운로드

📹 비대면 예약 확정 시 Zoom 자동 생성

4

가용시간 등록

상담 가능 요일·시간 등록 및 관리

5

예약 확정 방법

내담자 예약 신청 확인 · 일정 조정 · 확정

  1. 단계 1대시보드의 대기 중인 예약 알림 또는 사례 상세 왼쪽 대기 중인 예약 신청 영역에서 신규 요청을 확인합니다.
  2. 단계 2처리하기 또는 예약 확인 및 확정 버튼을 클릭해 예약 처리 화면으로 이동합니다.
  3. 단계 3내담자가 신청한 상담 희망 시간을 확인하고, 필요하면 시간 수정으로 일정을 조정합니다.
  4. 단계 4일정이 맞으면 예약 확정 버튼을 클릭합니다. 확정 후 내담자에게 안내 메일이 발송됩니다.

비대면 사례는 예약 확정 시 Zoom 회의가 자동 생성되며, 사례 상세에 회의 링크가 저장됩니다. 대면 사례는 확정된 일시·장소를 내담자와 채팅 등으로 안내해 주세요.

매칭 대기 목록 → 상담사 배정 → 사례 생성

③ 담당 상담사·총 회기 수 입력 후 저장
