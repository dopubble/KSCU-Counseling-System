KSCU Counseling Platform

전문상담사 수련과정
플랫폼 이용 매뉴얼

숭실사이버대학교 평생교육원 상담센터 통합 플랫폼의 주요 기능을 역할별(내담자 · 상담사 · 관리자)로 안내합니다.

🌐 플랫폼 접속 📅 최종 업데이트: 2026년 6월

내담자(Client)란?

상담을 신청하고 받는 이용자입니다. 회원가입 후 관리자 승인 없이 즉시 로그인하여 상담 신청·예약·자료 공유·채팅·Zoom 상담까지 이용할 수 있습니다.

1. 회원가입 및 즉시 로그인

내담자는 가입 유형에서 「내담자」를 선택하면, 관리자 승인 절차 없이 가입과 동시에 계정이 활성화(ACTIVE)됩니다. 가입 완료 후 자동으로 로그인되어 내 상담실(대시보드)로 이동합니다.

  1. 1
    회원가입 — 상단 메뉴 또는 홈 화면에서 「회원가입」 클릭 → /accounts/signup/
  2. 2
    가입 유형 「내담자」 선택, 이메일·이름·생년월일·학생 여부 등 필수 정보 입력
  3. 3
    이용약관 동의 후 「가입하기」 — 곧바로 로그인되어 대시보드로 이동
  4. 4
    상담 신청 — 「상담 신청」 메뉴(/counseling/apply/)에서 호소 문제·희망 일정 등 작성 후 제출
💡 참고: 상담사 계정과 달리 내담자는 「승인 대기」 화면 없이 바로 서비스를 이용할 수 있습니다.

2. 상담 상세페이지 & 상담 방식 확인

관리자가 상담사를 배정하면 내 상담실 → 상담 상세 페이지에서 사례 정보를 확인할 수 있습니다.

  1. 1
    대시보드에서 진행 중인 사례 카드를 클릭하거나, 사례번호 링크로 상세 페이지 진입
  2. 2
    좌측 「내 상담 정보」 영역에서 이름 옆 「상담진행방식: 대면 / 비대면」 라벨 확인
  3. 3
    담당 상담사 정보(이름·이메일) 및 상담사 가용·차단 일정 목록도 함께 표시됩니다

🏢 대면 (IN_PERSON)

센터 또는 지정 장소에서 대면 상담이 진행됩니다.

💻 비대면 (REMOTE)

Zoom 화상 상담으로 진행됩니다. 회기 카드에 Zoom 버튼이 표시됩니다.

3. 1:1 실시간 채팅 및 알림

담당 상담사가 배정된 사례 상세 페이지에서만 우측 하단 플로팅 채팅 버튼이 나타납니다.

  1. 1
    화면 우측 하단 💬 채팅 아이콘 버튼 클릭 → 채팅 패널 열림
  2. 2
    메시지 입력 후 전송 — 상담사와 실시간 1:1 대화 (폴링 방식 갱신)
  3. 3
    채팅창을 닫아 두면, 상담사의 새 메시지가 올 때 버튼 위 🔴 빨간색 알림 배지가 표시됩니다
  4. 4
    채팅을 다시 열면 읽음 처리되며 배지가 사라집니다
채팅은 사례 상세 페이지에 있을 때만 동작합니다. 다른 메뉴로 이동하면 자동으로 폴링이 중지됩니다.

4. 파일 첨부 및 공유

  1. 1
    상담 상세 페이지 하단 회기별 카드 영역으로 이동
  2. 2
    해당 회기의 「📎 자료 첨부」 버튼 클릭
  3. 3
    과제, 심리검사 결과지, 상담 관련 자료 등 파일 선택 후 업로드
  4. 4
    업로드된 파일은 담당 상담사가 같은 회기 카드에서 즉시 확인·다운로드할 수 있습니다

5. 비대면 Zoom 상담 참여

상담진행방식이 비대면이고, 해당 회기 예약이 확정(CONFIRMED)된 경우에만 Zoom 버튼이 활성화됩니다.

  1. 1
    상담 상세 페이지 회기 카드에서 「📹 Zoom 회의 바로가기」 버튼 확인
  2. 2
    예약된 상담 시작 시간에 맞춰 버튼 클릭 → Zoom 회의실 새 탭에서 접속
  3. 3
    카메라·마이크 권한 허용 후 상담사와 화상 상담 진행
Zoom 링크는 상담사가 예약을 확정할 때 자동 생성·등록됩니다. 버튼이 보이지 않으면 예약 확정 여부를 확인하세요.
신규

6. 이용 가능 / 불가 시간 입력

2회기 이후 예약을 원활히 조율하기 위해, 내담자는 마이페이지(내정보 수정) 또는 상담 상세 → 회기 예약 화면에서 본인의 상담 가능·불가 시간대를 등록합니다.

  1. 1
    우측 상단 프로필 메뉴 → 「내정보 수정」 (/accounts/profile/) 진입
  2. 2
    「상담 가능 시간」 섹션에서 캘린더 또는 주간 타임테이블 뷰 선택
  3. 3
    가능한 시간대는 초록색, 불가능한 시간대는 빨간색으로 드래그 또는 클릭하여 표시
  4. 4
    「저장하기」 클릭 — 담당 상담사가 예약 조율 시 해당 정보를 참고합니다

※ 상담 상세 페이지에서 회기 예약 시에도 달력 UI를 통해 상담사 가용 시간(가능/불가)을 함께 확인할 수 있습니다.

신규

7. 2회기 이후 예약 확인 및 확정

1회기 종료 후, 상담사와 다음 회기 일정을 조율합니다. 상담사가 제안한 일정을 확인하고 승인하거나, 직접 희망 일시를 신청할 수 있습니다.

📋 예약 프로세스 흐름

내담자 시간 입력 → 상담사 일정 제안/등록 → 내담자 확인 → 예약 확정
  1. 1
    상담 상세 페이지 회기 카드에서 해당 회기(2회기, 3회기 …) 확인
  2. 2
    상담사가 제안한 일정이 있으면 회기 상태가 「예약 요청」으로 표시되고 희망 일시가 보입니다
  3. 3
    일정이 맞으면 「✅ 예약 확정 / 승인」 버튼 클릭 — 최종 예약 완료
  4. 4
    직접 예약하려면 「📅 상담일정 예약」 버튼 → 달력에서 상담사 가용 시간 선택 → 신청
  5. 5
    상담사 확정 후 회기 상태가 「예약 확정」으로 변경되며, 비대면인 경우 Zoom 버튼 활성화
⚠️ 상담 24시간 이내에는 일정 변경·취소가 제한될 수 있습니다. 미리 조율해 주세요.

상담사(Counselor)란?

수련과정 전문상담사로, 관리자 배정을 통해 내담자를 담당합니다. 회원가입 후 관리자 승인이 완료되어야 로그인 및 업무가 가능합니다.

1. 회원가입 및 승인 대기

  1. 1
    회원가입 시 가입 유형 「상담사」 선택 후 정보 입력·제출
  2. 2
    가입 완료 후 계정 상태가 「승인대기(PENDING)」로 저장 — 이 상태에서는 로그인 불가
  3. 3
    관리자가 Django Admin 또는 운영 화면에서 계정 상태(ACTIVE) 및 상담사 프로필 승인(is_approved)·기수를 설정
  4. 4
    승인 완료 후 로그인 → 상담사 대시보드에서 배정 사례 확인
🔒 승인 전 로그인 시도 시 「이메일 또는 비밀번호가 올바르지 않습니다」 또는 「승인 대기」 안내가 표시됩니다.

2. 배정 사례 및 상담 방식 관리

  1. 1
    로그인 후 「내 사례」 대시보드(/counseling/counselor/)에서 배정된 내담자 목록 확인
  2. 2
    사례 상세 페이지 진입 → 내담자 정보·사례번호·남은 회기 수 확인
  3. 3
    사례 정보에서 상담진행방식(대면/비대면) 확인 — 비대면 사례는 Zoom 연동 대상

3. 내담자 파일 확인

  1. 1
    사례 상세 페이지 각 회기 카드의 자료 영역 확인
  2. 2
    내담자가 업로드한 과제·검사 결과·첨부파일 목록이 실시간으로 표시
  3. 3
    파일명 클릭 → 다운로드하여 상담 준비·기록에 활용

4. 1:1 채팅 및 Zoom 조율

💬 1:1 채팅

  1. 1
    사례 상세 페이지 우측 하단 플로팅 채팅 버튼 클릭
  2. 2
    내담자와 실시간 메시지 교환 — 일정·과제·Zoom 안내 등 자유롭게 소통
  3. 3
    채팅창을 닫은 상태에서 새 메시지 수신 시 🔴 알림 배지 표시

📹 Zoom (비대면)

  1. 1
    내담자의 예약 요청을 「예약 확인 및 확정」 처리하면 Zoom 회의가 자동 생성
  2. 2
    확정된 회기 카드의 Zoom 링크로 회의 시작 — 내담자도 동일 링크로 접속
  3. 3
    일정 변경 시 시스템이 Zoom 회의 시간을 함께 갱신
신규

5. 내담자 가능 시간 확인 및 일정 요청

  1. 1
    사례 상세 또는 내담자 프로필에서 내담자가 입력한 가능/불가 시간 확인
  2. 2
    본인의 「가용 시간」 메뉴(/scheduling/availability/)에서 매주 반복·특정 날짜·가능/차단 시간 등록
  3. 3
    양측 일정을 조율한 뒤, 사례 상세 「대기 중인 예약 신청」 위젯 또는 회기 카드에서 다음 회기 일시 등록
  4. 4
    「예약 확인 및 확정」 클릭 → 내담자에게 확정 알림 발송 (비대면 시 Zoom 자동 생성)
  5. 5
    내담자가 직접 예약 요청한 경우, 좌측 「대기 중인 예약 신청」 알림에서 검토 후 확정/반려

관리자(Admin)란?

센터 운영 담당자로, 상담사 승인·내담자-상담사 매칭·일정 모니터링·통계 등 플랫폼 전반을 관리합니다. 관리자 패널(/admin-panel/)과 Django Admin(/admin/)을 함께 사용합니다.

1. 상담사 계정 승인

  1. 1
    Django Admin → 사용자(Users) 목록에서 신규 상담사 계정 검색
  2. 2
    계정 상태(status)를 ACTIVE로 변경 → is_active가 자동으로 True 설정
  3. 3
    하단 상담사 프로필(CounselorProfile)에서 승인(is_approved) ✓ 체크 및 기수(cohort) 입력 (필수)
  4. 4
    저장 — 상담사가 로그인하여 대시보드 이용 가능
운영 패널 「기수별 상담사 명단」(/admin-panel/counselors/)에서 승인·기수 현황을 한눈에 확인할 수 있습니다.

2. 매칭 데이터 및 Zoom 링크 주입

🔗 내담자–상담사 매칭

  1. 1
    관리자 패널 → 상담 통합 관리 또는 상담사 매칭 (/admin-panel/matching/)
  2. 2
    「매칭 대기」 필터에서 신규 내담자 신청 목록 확인
  3. 3
    해당 신청 → 「상담사 배정」 → 담당 상담사·총 회기 수 입력 후 저장
  4. 4
    사례(Case) 생성 및 내담자·상담사에게 알림 발송

📦 일괄 1회기 매칭 (운영)

  1. 1
    기수별 JSON/CSV 매칭 데이터 준비
  2. 2
    서버에서 python manage.py import_session1_matches 실행
  3. 3
    내담자–상담사 배정 + 1회기 확정 예약 일괄 생성

📹 Zoom 링크 (비대면)

  • 비대면(REMOTE) 사례는 상담사가 예약 확정 시 Zoom API로 회의 자동 생성
  • 생성된 URL은 사례(Case.zoom_meeting_url)에 저장
  • 환경 변수 ZOOM_ACCOUNT_ID, ZOOM_CLIENT_ID, ZOOM_CLIENT_SECRET 설정 필요
  • 수동 주입이 필요한 경우 Django Admin → 사례(Case)에서 Zoom URL 직접 입력 가능
신규

3. 예약 및 스케줄 현황 모니터링

2회기부터 내담자와 상담사가 상호 조율하여 확정하는 예약 전반을 관리자가 모니터링합니다.

  1. 1
    관리자 대시보드 — 오늘 예약·매칭 대기·취소 요청 대기 건수 위젯 확인
  2. 2
    상담 통합 관리 → 진행 중인 상담 탭 — ACTIVE 사례·담당 상담사·회기 현황
  3. 3
    취소 대기 목록(/admin-panel/cancel-pending/) — 내담자 취소 요청 건 검토
  4. 4
    일정 분쟁·조율 지연 시 Django Admin에서 예약(Appointment) 상태 직접 확인·조정
  5. 5
    중복 매칭대기 신청 정리: python manage.py repair_stale_applications --dry-run
예약 상태 의미
PENDING예약 요청 접수 — 상담사 확정 대기
CONFIRMED예약 확정 — Zoom 링크 활성(비대면)
CANCEL_PENDING취소 요청 — 상담사/관리자 처리 대기
COMPLETED상담 완료
