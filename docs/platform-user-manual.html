내담자(Client) 이용 가이드

상담을 신청하고 받는 이용자입니다. 회원가입 후 관리자 승인 없이 즉시 로그인하여 상담 신청·예약·자료 공유·채팅·Zoom 상담까지 이용할 수 있습니다.

1

회원가입 및 즉시 로그인

내담자 선택 시 승인 없이 바로 ACTIVE · 자동 로그인

  1. ①상단 메뉴 「회원가입」 클릭
  2. ②가입 유형 「내담자」 선택, 필수 정보 입력
  3. ③이용약관 동의 후 가입 → 곧바로 내 상담실로 이동
💡 상담사와 달리 내담자는 「승인 대기」 화면 없이 바로 서비스를 이용합니다.
2

상담 신청 & 내 상담실

대시보드에서 진행 현황 확인 · 상담 신청서 작성

내 상담실에서 신청·배정·진행 중인 사례를 카드 형태로 확인합니다.

상담 신청 메뉴에서 호소 문제, 희망 일정, 상담 유형을 작성해 제출합니다.

3

상담 상세 & 진행 방식 확인

대면 / 비대면 라벨 · 담당 상담사 · 회기별 카드

🏢 대면

센터 또는 지정 장소

💻 비대면

Zoom 화상 상담

① 대시보드에서 사례 카드 클릭

② 「상담진행방식: 대면/비대면」 확인

③ 회기별 예약·자료·Zoom 버튼 확인

4

1:1 실시간 채팅

사례 상세 페이지 우측 하단 플로팅 버튼

💬 채팅 아이콘 클릭 → 상담사와 1:1 대화

🔴 창을 닫아 두면 새 메시지 시 알림 배지 표시

다른 메뉴로 이동하면 폴링이 자동 중지됩니다.

5

비대면 Zoom 상담

비대면 + 예약 확정(CONFIRMED) 시 Zoom 버튼 활성화

📹 회기 카드의 「Zoom 회의 바로가기」 → 새 탭에서 화상 상담 접속

① 상담진행방식이 비대면인지 확인

② 해당 회기가 예약 확정 상태인지 확인

③ 상담 시작 시간에 Zoom 버튼 클릭

신규

6. 이용 가능 / 불가 시간 입력

마이페이지 또는 상담 상세 → 회기 예약에서 가능·불가 시간 등록

🟢 가능 · 🔴 불가 시간을 캘린더에 표시 후 저장

신규

7. 2회기 이후 예약 확정

상담사 제안 일정 → 예약 확정 또는 직접 「상담일정 예약」

확정 후 비대면 사례는 Zoom 버튼 활성화

상담사(Counselor) 이용 가이드

수련과정 전문상담사로, 회원가입 후 관리자 승인이 완료되어야 로그인 및 업무가 가능합니다.

1

회원가입 및 승인 대기

PENDING 상태에서는 로그인·업무 불가

① 가입 유형 「상담사」 선택 후 제출

② 계정 상태 PENDING → 승인 대기 화면

③ 관리자가 ACTIVE + is_approved + 기수 설정

④ 승인 후 로그인 → 상담사 대시보드

🔒 승인 전에는 로그인하더라도 「승인 대기」 안내가 표시됩니다.
2

배정 사례 대시보드

내담자 목록 · 사례 상태 · 빠른 접근

3

사례 상세 · 채팅 · 파일 · Zoom

회기 카드 · 1:1 채팅 · 내담자 첨부 자료

💬 우측 하단 채팅으로 일정·과제 안내

📎 회기별 내담자 첨부 파일 다운로드

📹 비대면 예약 확정 시 Zoom 자동 생성

4

가용 시간 & 2회기 이후 예약

내담자 가능 시간 확인 · 일정 제안 · 예약 확정

예약 흐름: 내담자 시간 입력 → 상담사 일정 제안 → 내담자 확인 → 예약 확정

관리자(Admin) 이용 가이드

상담사 승인·내담자-상담사 매칭·일정 모니터링·통계 등 플랫폼 전반을 관리합니다.

1

관리자 대시보드

오늘 예약 · 매칭 대기 · 취소 요청 한눈에

2

내담자–상담사 매칭

매칭 대기 목록 → 상담사 배정 → 사례 생성

① 상담사 매칭 → 「매칭 대기」 필터

② 신청 선택 → 상담사 배정

③ 담당 상담사·총 회기 수 입력 후 저장

④ Case 생성 및 알림 발송

3

상담 통합 관리 & 모니터링

진행 중 상담 · 예약 상태 · 취소 대기

예약 상태 의미
PENDING예약 요청 — 상담사 확정 대기
CONFIRMED예약 확정 — Zoom 활성(비대면)
CANCEL_PENDING취소 요청 처리 대기
